# objects — substantivele repo-ului

O fișă pe lucru. Deschizi `_index.md`, alegi fișa, o citești, urmezi citarea în sursă. Nu citi tot folderul.

Clustere (după cum întreabă cel care editează, nu după foldere):

| Cluster | Fișe |
|---|---|
| site | `tara.md`, `config-tara.md` |
| continut | `pagina.md`, `model-casa.md`, `imagini.md` |
| sablon | `sablon-partajat.md` |
| date | `traduceri.md` |
| livrare | `deploy.md`, `previzualizare-locala.md` |

O fișă nouă = copie a `../_templates/object.md`, apoi `../_scripts/regenereaza.sh` reface `_index.md`.
