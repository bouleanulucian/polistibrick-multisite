# Polistibrick — Translation Brief

## 🏗 Despre companie

**Polistibrick** este o companie europeană de tehnologie pentru construcții.
Vinde un **sistem ICF (Insulated Concrete Forms / Cofraj termoizolant pierdut)** — sistemul complet pentru construirea unei case pasive A+++.

### Ce face Polistibrick UNIC pe piață:
Este **singurul sistem ICF complet** care acoperă întreaga structură:
- **MBK** = Pereți (Walls / Murs / Pareti / Muros / Muren / Wände)
- **PBK** = Planșee (Floors / Planchers / Solai / Forjados / Vloeren / Decken)
- **TBK** = Acoperiș (Roof / Toit / Tetto / Tejado / Dak / Dach)

Concurența vinde DOAR pereți ICF. Polistibrick vinde sistemul integral.

### Specificații tehnice cheie:
- Standard **A+++** (passive house maxim)
- Rezistență la foc **A1** (cea mai înaltă clasă, necombustibil)
- **REI 240** (rezistență structurală la foc 240 minute)
- Sistem **5-în-1**: izolație + foc A1 + antiseismic + hidrofug + acustic — toate într-un singur panou
- Construcție rapidă: **4 săptămâni** (vs 4-7 luni pentru cărămidă)
- **Brevetat european** (patent propriu)
- Fabricat în UE

## 🎯 Audiența țintă

3 tipuri de cumpărători:
1. **Proprietar** (owner) — vrea casa lui premium, fără facturi
2. **Arhitect/Inginer** — vrea tehnic, certificări, BIM, suport
3. **Dezvoltator** — vrea ROI, ansambluri Passivhaus, profit

## ⚠️ Reguli de aur

1. **Păstrează STRUCTURA HTML EXACT.** Nu adăuga/elimina tag-uri, nu schimba ordinea.
2. **Păstrează ATRIBUTELE TEHNICE EXACT.** Numai `alt`, `title`, `aria-label`, `placeholder` se traduc.
3. **TRADUCE NATURAL, NU LITERAL.** Pentru fiecare frază, gândește: "Ce ar spune un nativ care vinde construcții premium?"
4. **PĂSTREAZĂ VOCEA PREMIUM.** Polistibrick nu se târguie. Nu folosi "ieftin", "reducere", "discount".
5. **TERMINOLOGIA TEHNICĂ TREBUIE SĂ FIE CORECTĂ.** Vezi `GLOSSARY.md`.
6. **NU INVENTA INFORMAȚII.** Dacă nu ești sigur de un termen tehnic, folosește versiunea engleză internațională (ex: "ICF", "EPS").
7. **NUMERELE RĂMÂN.** "4 săptămâni" → "4 weeks", nu "four weeks".
8. **EMOJI-URILE RĂMÂN.** Nu le traduce, nu le elimina.
